# Identidade e demonstração

`preview.svg` é um desenho vetorial próprio com uma visualização do tabuleiro final do replay de seed 42. As células são extraídas da saída real do programa por `scripts/gerar_preview.py`.

Ele não é uma captura da interface de terminal: é uma ilustração documental do resultado. A interface real usa caracteres e cores ANSI. Não há sprites, logotipos comerciais, fontes externas ou imagens retiradas de outro projeto.
