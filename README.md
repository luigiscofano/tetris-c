# Tetris em C

Implementação nova de portfólio preparada em 2026 com assistência de IA. O fonte acadêmico original não foi recuperado. Esta primeira entrega contém o motor C11 e seus testes de comportamento.

Execute `make test` para verificar formas, colisões, rotações, linhas, pontos, pausa e conservação do tabuleiro em 200 mil ações.
